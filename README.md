# About Mockup Project

This mockup will be a platform shooter as a ghost. The player must dodge or destroy other ghosts and cursed objects to make it out of the purgatory he's stuck in.


The plans are to have the ghost attack using various sorts of attacks. For early stages it will be a simple "fireball". However, I would like to add other powerups the player can use to fight enemies in creative ways and make it more engaging.

Storyline is still a work in progress, this was initially going to be simply a puzzle game, however using combat elements would definitely make it more engaging.
